# Valio web app

The order console: Vite, React, shadcn/ui (Base UI, nova preset) and TanStack Router with
file-based routes. Setup, ports and features are in the root [README](../../README.md).

- One feature per route file in `src/routes/` and one folder in `src/features/<feature>/`; add the
  nav entry in `src/components/layout/app-shell.tsx`. `src/routeTree.gen.ts` is generated by the
  router plugin on `pnpm dev`/`pnpm build` and checked in.
- `pnpm lint` (oxlint, `react/no-danger` is an error), `pnpm typecheck`, `pnpm test` (Vitest),
  `pnpm fmt` (Prettier).
- `src/features/journal-viewer/journal.types.ts` is generated from the skill's
  `journal.schema.json` with `pnpm gen:journal-types`; a test fails while it is stale.
- Add shadcn components with `pnpm dlx shadcn@latest add <name>`.
